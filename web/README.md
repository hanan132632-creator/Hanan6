# 🏰 موقع عقارات النخبة (Elite Real Estate Web)

نسخة طبق الأصل في الجودة والشكل والفخامة من **تطبيق عقارات النخبة (أندرويد)**، مجهزة بنسبة 100% للرفع والنشر المباشر على **Vercel** و **GitHub**!

---

## 🌟 مميزات موقع الويب:
1. **نفس الهوية الملكية الفاخرة:** درجات الكحلي الداكن مع الذهب الخالص (`#D4AF37`) وخطوط عربية ملكية (Cairo / Tajawal).
2. **العقارات الفاخرة المعتمدة:**
   - قصر المها الملكي (حي حطين - 6,850,000 ريال)
   - بنتهاوس الأبراج العاجية (حي النرجس - 2,450,000 ريال)
   - أرض استثمارية تجارية (طريق الملك سلمان - 9,200,000 ريال)
   - فيلا إيوان الفاخرة (أبحر الشمالية - 4,800,000 ريال)
   - قصر اليمامة الأندلسي (الدرعية - 14,500,000 ريال)
   - شقة سكاي لاين الفاخرة (الكورنيش - 1,890,000 ريال)
3. **حاسبة التمويل العقاري التفاعلية:** حساب فوري للقسط الشهري، الدفعة الأولى، والأرباح البنكية.
4. **لوحة تحكم المشرف (Admin):** زر مخصص في الهيدر يتيح لكِ إضافة أي عقار جديد بصوره وسعره وتفاصيله فوراً ويتم نشره مباشرة!
5. **تحقيق الأرباح مع Monetag:** الروابط الذكية مدمجة في بروشورات الـ PDF (`https://omg10.com/4/11930497`).
6. **قسم تحميل تطبيق الأندرويد:** زر مباشر لتحميل ملف `app-elite-realestate.aab` و `APK`.

---

## 🚀 طريقة النشر على Vercel في دقيقة واحدة:

### الطريقة الأولى (عبر GitHub):
1. ارفعي محتويات هذا المجلد `web` إلى مستودع جديد على **GitHub**.
2. ادخلي على حسابك في **[Vercel](https://vercel.com)**.
3. اضغطي على **Add New Project** ثم اختاري المستودع من GitHub.
4. اضغطي **Deploy**!
5. سيعطيكِ Vercel رابط موقعك العالمي الفوري مجاناً مع شهادة أمان SSL!

### الطريقة الثانية (بدون كود أو أوامر):
* يمكنكِ ربط حساب GitHub بـ Vercel مباشرة وسيقوم بقراءة ملف `vercel.json` تلقائياً بدون أي إعدادات إضافية.
